## Conceito

- Métodos utilizados para separar os **componentes de uma [[Substâncias e misturas|mistura]]**.
- O método depende das propriedades dos componentes, como [[Densidade]], tamanho das partículas, solubilidade e temperatura de ebulição.

## Misturas heterogêneas

|Método|Utilizado para|Exemplo|
|---|---|---|
|**Catação**|Sólidos diferentes|Feijão + pedras|
|**Peneiração**|Sólidos de tamanhos diferentes|Areia + pedras|
|**Filtração**|Sólido + líquido|Água + areia|
|**Decantação**|Diferença de densidade|Água + óleo|
|**Centrifugação**|Acelera a decantação|Sangue|
|**Separação magnética**|Material magnético + não magnético|Ferro + areia|

## Misturas homogêneas

|Método|Utilizado para|Exemplo|
|---|---|---|
|**Evaporação**|Recuperar o sólido dissolvido|Sal + água|
|**Destilação simples**|Sólido + líquido|Água + sal|
|**Destilação fracionada**|Líquidos miscíveis|Água + etanol|

## Destilação

Baseia-se na diferença entre as **temperaturas de ebulição**.

### Simples

$$  
\text{vaporização} \rightarrow \text{condensação}  
$$

Permite recuperar o líquido de uma mistura como água + sal.

### Fracionada

Usada principalmente para separar **líquidos miscíveis com diferentes pontos de ebulição**.
